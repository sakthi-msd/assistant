# 🤖 AI Student Support Assistant

An AI-powered college student support assistant that helps students
get answers to college-related questions using official college
regulations, syllabus, FAQs, academic notices, and other documents.

## 🌐 Live Website

👉 [Visit AI Student Support Assistant](https://muthura267-a11y.github.io/ai-support-assistants/)

## 🎯 Project Objective

The main objective of this project is to provide students with a
smart AI assistant that can quickly answer college-related questions
using trusted college documents.

## 🚀 Key Features

- 💬 AI Student Chat Assistant
- 📚 College Knowledge Base
- 📄 Regulations & Syllabus Support
- 📝 FAQ Support
- 📢 Academic Notices
- 🔍 RAG-based Question Answering
- 🧠 AI Agent
- 🛠️ AI Tools
- 💾 Conversation Memory
- 📱 Responsive Web Design
